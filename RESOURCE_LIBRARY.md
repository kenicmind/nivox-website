# NIVOX Resource Library

The Resource Library now uses a structured metadata model in
`src/pages/Student/ResourcesPage.jsx`. Each resource has:

- title
- description
- category
- author
- version
- file size
- local PDF path

All current learning entries use the existing local NIVOX PDF as a safe,
copyright-free placeholder until official learning guides are approved. Replace
the `file` value for each entry with its final PDF path when ready.

# NIVOX Resource Library

The student resource library is driven by structured metadata in
`src/pages/Student/ResourcesPage.jsx`. The five bundled text guides are original
NIVOX quick-start resources and can be distributed with the application.

Each resource records its title, description, category, author, version, file
size, and public download path. Future licensed resources must be reviewed for
distribution rights before being added to `public/resources`.
